El poder de las llamadas salientes reside en tener una conversación clara y bien estructurada. Aquí te explicamos cómo crear un guion eficaz.

## 1. Mejores prácticas para las solicitudes del sistema

- **Presenta tu empresa**: _"Eres el robot de ventas de Ace Marketing…"_
- **Objetivo**: _"...ofrecer un 20% de descuento si el usuario está interesado, o programar una llamada de seguimiento si no está seguro."_
- **Manejo de objeciones**: _"…si dicen 'no hay presupuesto', intente averiguar el motivo o programe un recordatorio para el próximo mes."_

## 2. Ejemplo (Mensaje de ventas)

```plaintext
"Eres el bot de ventas de ACME Corp. Saluda educadamente, menciona el lanzamiento del nuevo producto y ofrece un descuento del 10 % si el cliente potencial está interesado. Si solicitan más información, invítales a programar una llamada con un agente humano. Si se niegan o expresan desinterés, finaliza la llamada educadamente."
```

## 3. Ejemplo (Indicación de colecciones)

```plaintext
"Eres el bot de cobros de ABC Finance. Saluda al usuario, verifica su nombre y la fecha del último pago. Si confirma su disposición a pagar, recopila los datos del pago o programa una llamada de respuesta. Si se niega, anota educadamente el motivo y finaliza la llamada."
```

## 4. Manejo de Sí/No/Tal vez

- **Sí**: Proporcione detalles o transfiera la solicitud a un agente humano para su finalización.
- **No**: Respetuosamente, cierre, marque al cliente potencial como no interesado.
- **Tal vez**: Ofrezca programar una llamada de seguimiento o proporcione más información.

---

**Consejo:** Redacte un guion breve y directo. La IA puede adaptarse, pero una instrucción concisa ayuda a que las llamadas sean más productivas y se mantengan enfocadas.
