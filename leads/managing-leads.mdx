Aprende a crear, editar y gestionar leads de forma eficaz para tus campañas con una configuración adecuada de variables y una gestión de contactos secundarios.

## Creación de un nuevo cliente potencial

### Información básica
1. **Número de teléfono:** Introduzca el número de contacto principal en formato internacional.
2. **Asignación de campaña:** Seleccione a qué campaña pertenece este cliente potencial.
3. **Estado:** Se establece automáticamente en "Creado" para los nuevos clientes potenciales

<Note>
**Formato del número de teléfono:** Utilice el formato internacional sin espacios ni paréntesis (+1234567890) para importaciones automatizadas y cargas de archivos.
</Note>

### Configuración de variables

#### Variables predeterminadas del asistente
Al seleccionar una campaña, el cliente potencial hereda automáticamente las variables de la [configuración del asistente](/ai-assistants/settings/prompt-and-tools#call-variables):
- **Valores predefinidos:** Las variables predeterminadas del asistente aparecen en el formulario
- **Personalización:** Modifique los valores específicos de este cliente potencial.
- **Campos obligatorios:** Algunas variables pueden ser necesarias para el funcionamiento de la campaña.

#### Variables personalizadas
Agrega información personalizada para que la use tu asistente de IA:

**Tipos de variables comunes:**
- **nombre_cliente:** Nombre de la persona para los saludos personalizados
- **Empresa:** Nombre comercial para conversaciones B2B  
- **última_interacción:** Contexto de la conversación anterior
- **Preferencias:** Preferencias o requisitos del cliente
- **rango_presupuesto:** Información financiera para llamadas de ventas

**Ejemplo de formato de variable:**
```json
{
  "nombre_del_cliente": "Sara Parker",
  "empresa": "TechStart Solutions", 
  "última_interacción": "Solicitó una demostración de las funciones premium",
  "hora_de_contacto_preferida": "Por la tarde, hora del Este",
  "sector": "Desarrollo de software"
}
```

### Contactos secundarios

Agrega números de teléfono adicionales para el mismo contacto cuando tengas varias formas de comunicarte con él.

#### Cuándo usar contactos secundarios
- **Responsables de la toma de decisiones:** Varias personas involucradas en la decisión
- **Números de respaldo:** móvil, oficina y casa de la misma persona
- **Contactos departamentales:** Diferentes departamentos en la misma empresa
- **Contactos basados ​​en el tiempo:** Números diferentes para diferentes momentos

#### Configuración de contacto secundario
1. **Agregar contacto secundario:** Haga clic en "Agregar contacto secundario" en el formulario.
2. **Número de teléfono:** Introduzca un número de teléfono adicional
3. **Variables:** Establezca variables específicas para este contacto (opcional)
4. **Orden:** Los contactos se prueban en el orden en que los agregas.

<Tip>
**El orden de los contactos es importante:** La campaña intentará contactar a los usuarios en secuencia. Coloque primero a los que tengan más probabilidades de responder.
</Tip>

#### Variables de contacto secundarias
Cada contacto secundario puede tener variables únicas:
- **Persona diferente:** usar variables de nombre y rol diferentes
- **Misma persona:** Utilizar la misma información personal pero diferentes preferencias de contacto.
- **Específico del departamento:** Personalizar según las necesidades específicas del departamento

**Ejemplo - Múltiples responsables de la toma de decisiones:**
```json
// Primario: CEO
{
  "contact_name": "Jhon Perez",
  "role": "CEO", 
  "decision_authority": "Aprobación final"
}

// Secundario: CTO  
{
  "contact_name": "Pedro Rojas",
  "role": "CTO",
  "decision_authority": "Decisiones técnicas"
}
```

## Edición de clientes potenciales existentes

### Modificar la información de los clientes potenciales
- **Número de teléfono:** Actualizar si cambia la información de contacto
- **Campaña:** Trasladar el cliente potencial a otra campaña si es necesario.
- **Estado:** Cambiar manualmente el estado para el control de la campaña

### Gestión de variables
- **Actualizar valores:** Modificar los valores de las variables existentes
- **Agregar variables:** Incluir nueva información para un mejor contexto de IA
- **Eliminar variables:** Borrar datos obsoletos o irrelevantes

<Warning>
**Compatibilidad de campañas:** Al cambiar de campaña, asegúrese de que las variables coincidan con la configuración del nuevo asistente.
</Warning>

### Gestión de contactos secundarios
- **Agregar contactos:** Incluir números de teléfono adicionales
- **Eliminar contactos:** Borre los números no válidos o innecesarios.  
- **Reordenar contactos:** Cambiar la prioridad de la secuencia de llamadas
- **Actualizar variables:** Modificar información específica del contacto

## Gestión del estado de los líderes

### Comprensión de los cambios de estado
El estado de los clientes potenciales se actualiza automáticamente en función de la actividad de la campaña:
- **Creado → Procesando:** Cuando la campaña comienza a llamar
- **Procesando → Completado:** Cuando la llamada se realiza correctamente o se alcanza el objetivo.  
- **Procesando → Reprogramado:** Cuando la llamada necesita reintentarse
- **Reprogramado → Máximo de reintentos:** Cuando se alcanza el límite de reintentos

### Control de estado manual
Puedes cambiar manualmente el estado del cliente potencial cuando sea necesario:

#### Restablecer para volver a llamar
**Establecido en "Creado":** Los reinicios provocan que se vuelva a llamar.
- **Caso de uso:** El cliente potencial solicitó una llamada de seguimiento a una hora específica.
- **Efecto:** El cliente potencial se reincorpora a la cola de campaña.
- **Consideraciones:** Respeta los límites de reintentos de la campaña

#### Marcar como completado
**Marcado como "Completado":** Impide que la campaña llame a este cliente potencial.
- **Caso práctico:** Objetivo alcanzado a través de otros canales
- **Efecto:** El cliente potencial queda excluido de futuras llamadas de campaña
- **Consideraciones:** No se puede restablecer automáticamente mediante una campaña.

#### Otros cambios de estado
- **"Programado":** En cola para el siguiente intento de reintento
- **"Máximo de reintentos":** Marcar manualmente como agotado
- **"Reprogramado":** Restablecer el temporizador de reintentos

<Tip>
**Estrategia de estado:** Utilice los cambios de estado manuales con moderación. Deje que la automatización de campañas gestione la mayoría de las actualizaciones de estado para un comportamiento coherente.
</Tip>

## Operaciones masivas

### eliminación masiva
Seleccione varios clientes potenciales y elimínelos:
1. **Filtrar clientes potenciales:** Utilice los filtros de la tabla para seleccionar clientes potenciales específicos.
2. **Seleccionar clientes potenciales:** Marque las casillas de los clientes potenciales que desea eliminar.
3. **Eliminación masiva:** Seleccione la acción de eliminación en el menú de acciones masivas.
4. **Confirma:** Revisa los cambios antes de aplicarlos.

### Exportación a granel
Exportar datos de clientes potenciales filtrados para su procesamiento externo:
- **Aplicar filtros:** Filtrar por campaña, estado, rango de fechas
- **Seleccionar columnas:** Elija qué datos exportar
- **Incluir contactos secundarios:** Opción para incluir contactos secundarios
- **Descargar:** Formato CSV para compatibilidad con hojas de cálculo

## Organización de clientes

Utilice filtros de tabla, ordenación y búsqueda para organizar los clientes potenciales por campaña, estado, rango de fechas o contenido variable.

## Integración de campaña

- **Una sola campaña** por cliente potencial
- **Herencia de variables** desde la configuración del asistente
- **Coordinación automática** con la programación de la campaña y la lógica de reintento

## Mejores prácticas

### Puntos clave
- **Formato de teléfono:** Formato internacional sin espacios (+1234567890)
- **Variables:** Utilice nombres coherentes e información relevante.
- **Contactos secundarios:** Ordenar por prioridad, evitar duplicados
- **Privacidad:** Cumplir con los requisitos de protección de datos
