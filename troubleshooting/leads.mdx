Soluciones rápidas para problemas comunes de gestión de clientes potenciales y problemas de importación.

## Problemas de importación de clientes potenciales

### La importación falla completamente.
**Error:** "Error al importar" o "Formato de archivo no compatible"

**Soluciones:**
1. **Verifique el formato del archivo:** Solo se permiten archivos CSV o Excel.
2. **Verifique la selección de la campaña:** asegúrese de que se haya seleccionado una campaña para importar.
3. **Límites de tamaño de archivo:** Para un rendimiento óptimo, mantenga los archivos por debajo de 10 MB.
4. **Problemas de codificación:** Guardar el archivo CSV con codificación UTF-8

### No se importan clientes potenciales
**Problema:** La importación se completa, pero no aparecen clientes potenciales.

**Soluciones:**
1. **Encabezados de columna:** Verifique que los encabezados coincidan con el formato requerido (teléfono, nombre, etc.).
2. **Validación de datos:** Compruebe que los números de teléfono tengan el formato correcto.
3. **Filas vacías:** Eliminar las filas vacías del archivo
4. **Campos obligatorios:** Asegúrese de que la columna del número de teléfono contenga datos válidos.

### Importación parcial exitosa
**Problema:** Algunos leads se importaron correctamente, otros fallaron.

**Soluciones:**
1. **Descargar informe de errores:** revise las filas con errores para detectar problemas específicos.
2. **Formato del número de teléfono:** Asegúrese de que sea en formato internacional (+1234567890)
3. **Detección de duplicados:** Eliminar números de teléfono duplicados
4. **Datos no válidos:** Corrija los números de teléfono malformados o los datos obligatorios faltantes.

### Retrasos en el procesamiento
**Problema:** La importación se muestra como en proceso durante un tiempo prolongado.

**Explicación:**
- Los archivos grandes se procesan en segundo plano.
- El tiempo de procesamiento aumenta con el tamaño del archivo.
- El sistema pone en cola múltiples importaciones.

**Soluciones:**
1. **Espere a que finalice:** revise las notificaciones para ver las actualizaciones.
2. **Divida los archivos grandes:** divídalos en lotes más pequeños (500-1000 contactos).
3. **Contacta con soporte:** Si el procesamiento supera los 30 minutos

## Problemas de gestión de clientes potenciales

### Los clientes potenciales no aparece en la campaña
**Problema:** El cliente potencial importado no se muestra en la campaña.

**Verificar:**
- Estado del cliente potencial (debe ser "Creado" o "Programado")
- Filtros de campaña o configuración de búsqueda
- El cliente potencial se marcó como completado por error.

**Soluciones:**
1. **Restablecer el estado del cliente potencial:** Cambiar el estado a "Creado" para volver a ponerlo en cola.
2. **Verificar la asignación de la campaña:** Comprobar que el cliente potencial esté asignado a la campaña correcta.
3. **Actualizar interfaz:** Recargar la página de la campaña

### Números de teléfono no válidos
**Problema:** Números de teléfono rechazados durante la importación

**Formatos comunes:**
- **Correcto:** +1234567890 (formato internacional)
- **Incorrecto:** (123) 456-7890, 123-456-7890, 1234567890

**Soluciones:**
1. **Formato estandarizado:** Convertir todos los números al formato +1234567890
2. **Eliminar formato:** Eliminar espacios, paréntesis y guiones.
3. **Códigos de país:** Añada el prefijo del código de país correspondiente.
4. **Herramientas de validación:** Utilice la validación del teléfono antes de importar

### Clientes potenciales duplicados
**Problema:** La misma persona aparece varias veces

**Prevención:**
1. **Limpieza de datos:** Eliminar duplicados antes de importar
2. **Validación telefónica:** Comprobar variaciones de formato del mismo número
3. **Coincidencia de nombres:** Identifica posibles duplicados por nombre + teléfono
4. **Eliminación de duplicados:** Utilice herramientas para identificar entradas similares.

### Los contactos secundarios no funcionan
**Problema:** No se llama a los contactos secundarios.

**Requisitos:**
- El contacto secundario debe tener un número de teléfono válido.
- El contacto principal debe alcanzar primero el número máximo de reintentos.
- La campaña debe configurarse para contactos secundarios.

**Soluciones:**
1. **Verificar la configuración:** Comprobar la configuración del contacto secundario
2. **Estado del contacto principal:** Asegúrese de que se haya intentado contactar con el contacto principal
3. **Configuración de la campaña:** Confirme que la llamada a contactos secundarios está habilitada.

## Problemas de variables y datos

### Errores de asignación de variables
**Problema:** Las variables personalizadas no se importan correctamente.

**Soluciones:**
1. **Encabezados de columna:** Deben coincidir exactamente con [ la configuración del asistente](/ai-assistants/settings/prompt-and-tools#call-variables)
2. **Tipos de datos:** Asegúrese de que los datos coincidan con los tipos de variables esperados.
3. **Variables requeridas:** Incluir todas las variables definidas en el asistente.
4. **Valores predeterminados:** Compruebe si se están aplicando los valores predeterminados.

### Información de contacto faltante
**Problema:** Faltan nombres, correos electrónicos o datos personalizados en los clientes potenciales.

**Soluciones:**
1. **Asignación de columnas:** Verifique que todas las columnas estén asignadas correctamente.
2. **Campos opcionales:** Confirme que los campos opcionales se incluyen en la importación.
3. **Validación de datos:** Comprobar que los datos de origen estén completos.
4. **Reimportar:** Agregue los datos faltantes y vuelva a importar si es necesario.

## Problemas de integración de campañas

### Problemas de estado de cliente potencial
**Problema:** Los clientes potenciales se quedan atascados en un estado incorrecto.

**Significados de los estados:**
- **Creado:** Listo para ser llamado
- **Programado:** En cola para el próximo intento
- **Procesando:** Actualmente se está llamando
- **Completado:** Finalizado o meta alcanzada
- **Máximo de reintentos:** Se ha alcanzado el límite de reintentos.

**Soluciones:**
1. **Cambio de estado manual:** Actualizar el estado en la tabla de clientes potenciales.
2. **Reinicio de campaña:** Pause y reinicie la campaña si es necesario.
3. **Configuración de reintentos:** Ajuste el número máximo de reintentos o intervalos

### Problemas de herencia de variables
**Problema:** Las variables principales no funcionan en las llamadas

**Soluciones:**
1. **Configuración del asistente:** Verifique las variables definidas en [la configuración del asistente.](/ai-assistants/settings/prompt-and-tools#call-variables)
2. **Nombres de variables:** Asegurar la coincidencia exacta entre los datos del cliente potencial y las variables del asistente.
3. **Formato de datos:** Compruebe que los datos de la variable tengan el formato esperado.
4. **Llamadas de prueba:** Utilice llamadas de prueba manuales para verificar el paso de variables.

## Problemas con el formato de archivo

### Problemas con CSV
**Problemas comunes:**
- Delimitador incorrecto (use coma, no punto y coma)
- Faltan encabezados en la primera fila
- Campos entrecomillados con comillas sin escape
- Codificación mixta (usar UTF-8)

**Soluciones:**
1. **Formato estándar:** Utilice valores separados por comas
2. **Encabezados obligatorios:** La primera fila debe contener los nombres de las columnas.
3. **Calificación del texto:** Utilice comillas dobles para los campos de texto.
4. **Codificación:** Guardar como CSV codificado en UTF-8

### Problemas de Excel
**Problemas comunes:**
- Varias hojas (solo se importa la primera hoja)
- Celdas fusionadas que provocan desalineación de datos
- Fórmulas en lugar de valores
- Caracteres ocultos o formato

**Soluciones:**
1. **Una sola hoja:** Utilice únicamente la primera hoja de cálculo.
2. **Separar celdas:** Separar celdas fusionadas
3. **Solo valores:** Convertir fórmulas a valores
4. **Formato limpio** Eliminar formato especial

## Obtener ayuda

### Antes de contactar con el soporte técnico
1. **Descargar informe de errores:** Revisar mensajes de error específicos
2. **Comprobar formato de archivo:** Verificar la compatibilidad con el formato CSV/Excel
3. **Prueba con un lote pequeño:** Intenta importar primero entre 5 y 10 clientes potenciales.
4. **Revisar la documentación:** Verificar los requisitos de importación

### Información que se debe proporcionar
- Mensajes de error recibidos
- Ejemplo de archivo de importación (con datos confidenciales eliminados)
- Configuración y requisitos de la campaña
- Comportamiento esperado frente al comportamiento real
- Configuración de variables del asistente

<Warning>
**Privacidad de datos:** Elimine la información confidencial de los archivos de muestra antes de compartirlos con el soporte.
</Warning>
