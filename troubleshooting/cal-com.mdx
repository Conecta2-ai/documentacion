Esta guía proporciona soluciones para problemas comunes que se presentan al integrar Cal.com con su asistente de IA.

## Problemas de programación de citas

### Error de clave API faltante

**Problema:** Se produce el error "falta la clave API o el ID del evento para Cal.com".

**Solución:**
1. Ve a [la configuración del asistente](/ai-assistants/settings/prompt-and-tools#default-tools)
2. Diríjase a la sección **de Programación de citas** 
3. **Introduce la clave API correcta** de tu configuración de desarrollador de Cal.com.
4. **Introduce el ID de evento correcto** de la URL de tu evento de Cal.com
5. **Haz clic en Guardar** para aplicar la configuración.
6. **Verifique que** la conexión aparezca como activa.

### Problemas de conexión

**Problemas de configuración de la API:**
- **Verifique que la clave API** esté activa y tenga los permisos correctos en Cal.com.
- **Comprueba que el ID del evento** sea correcto en la URL de tu evento de Cal.com.
- **Confirma el acceso ** a la cuenta de Cal.com

### Problemas de configuración del evento

**Eventos no programados:**
- **No se requieren campos personalizados:** Asegúrese de no haber agregado ningún campo personalizado obligatorio en la configuración de eventos de Cal.com. Solo se admiten los campos predeterminados y el campo de teléfono opcional.
- **Identificador del campo de teléfono:** Verifique que el identificador del campo de teléfono sea exactamente "phone" (distingue entre mayúsculas y minúsculas).
- **Disponibilidad del evento:** Comprueba que tu evento de Cal.com tenga configurada la disponibilidad correctamente.

### Fallos en las reservas

**Citas que no se programan:**
- **Asegúrese de que el asistente tenga un correo electrónico definido en [la configuración del asistente](/ai-assistants/settings/prompt-and-tools#call-variables) y que el cliente potencial tenga un correo electrónico en las variables de entrada o en la conversación.
- **Configuración del campo de teléfono:** Agregue el campo de teléfono en la configuración del evento de Cal.com con el identificador "phone". Consulte [Número de teléfono en eventos del calendario](/ai-assistants/cal-com-scheduling#phone-number-in-calendar-events) para obtener información detallada sobre la configuración.
- **Prueba con llamadas reales:** Realiza llamadas de prueba utilizando una llamada telefónica (no una llamada web) para asegurar la correcta transmisión de variables.
- **Verifique las zonas horarias** - asegúrese de que la configuración de la zona horaria sea correcta en ambos sistemas.
- **Revisar los registros del asistente** - consultar las transcripciones de llamadas para ver los intentos de reserva.
- **Verifica la configuración del evento** en Cal.com para conocer las restricciones de reserva.

### Problemas de contacto con el cliente

**No se enviaron las invitaciones del calendario:**
- **Variable de correo electrónico:** Confirme que `email` la variable esté configurada correctamente en[los ajustes del asistente.](/ai-assistants/settings/prompt-and-tools#call-variables)
- **Correo electrónico del cliente potencial:** Verifique que el correo electrónico del cliente se esté enviando correctamente al crear clientes potenciales.
- **Formato de correo electrónico:** Asegúrese de que las direcciones de correo electrónico tengan un formato válido.

**Número de teléfono que no aparece en los eventos:**
- **Configuración del campo de teléfono: ** Verifique que el campo de teléfono esté configurado en los ajustes del evento de Cal.com con el identificador "phone". Consulte [ Número de teléfono en eventos del calendario](/ai-assistants/cal-com-scheduling#phone-number-in-calendar-events) para obtener más detalles sobre la configuración.
- **Método de llamada de prueba:** Utilice una llamada telefónica (no una llamada web) para realizar las pruebas y asegurar la transmisión de variables telefónicas.

## Obtener ayuda

Si estas soluciones no resuelven su problema:

1. **Revisa las transcripciones de las llamadas** para ver exactamente qué intentó la IA.
2. **Prueba la integración** con una reserva de citas sencilla mediante llamadas telefónicas.
3. **Contacta con el servicio de asistencia técnica** e incluye mensajes de error específicos y capturas de pantalla.

**Información de soporte común necesaria:**
- Captura de pantalla del mensaje de error
- Detalles de configuración del evento de Cal.com
- Configuración del asistente
- Transcripción de llamada que muestra el intento de reserva
