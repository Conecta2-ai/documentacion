Esta guía ayuda a resolver problemas comunes de integración SIP al conectar su proveedor SIP a Conecta2.ai.

## Estrategia de prueba

1. **Primero prueba las llamadas salientes** - son más fáciles de configurar.
2. **Prueba las llamadas entrantes en segundo lugar** - después de que funcionen las salientes.

## Problemas de SIP saliente

### Problemas de conexión

**El enlace troncal SIP no se conecta para llamadas salientes:**

1. **Verificar credenciales SIP** - nombre de usuario, contraseña, detalles del servidor.
2. **Selección del tipo de teléfono** - consulte con su proveedor para obtener el tipo correcto
3. **Configuración de IP fija** - normalmente se activa e introduce la dirección IP del proveedor.
4. **Configuración del proveedor** - verifique la configuración del códec, el transporte y el puerto.

### Problemas de registro SIP

**Importante:** Plataforma Conecta2.ai:
- **No envía** mensajes SIP REGISTER a su proveedor
- **No requiere** recibir el registro SIP de su proveedor.
- Utiliza **la autenticación de llamada directa** en su lugar

### Pruebas de salida

1. Configurar los ajustes del enlace troncal SIP
2. **Realiza una llamada de prueba directa** a través de la plataforma.
3. Revise los registros de llamadas para detectar errores.

## Problemas de SIP entrante

### Configuración de autenticación

**Para llamadas entrantes:**

1. **Utilice la autenticación por IP** - en lugar de nombre de usuario/contraseña.
2. **Lista blanca de direcciones IP de proveedores** - añade TODAS las direcciones IP de los proveedores a nuestra plataforma.
3. **Configuración del proveedor - IMPORTANTE**
   - **Utilice nuestro dominio FQDN** para el enrutamiento (NO la IP de salida).
   - **Enviar al dominio** - garantiza el enrutamiento correcto
   - **NO enviar a esta IP** - causa problemas de enrutamiento.

### Problemas comunes de entrada

**Las llamadas no llegan al asistente:**
- Verifique que todas las direcciones IP de los proveedores estén en la lista blanca.
- Asegúrese de que el proveedor envíe la información al dominio FQDN (no a la IP).
- Comprobar formato del número de destino

## Cuestiones generales

**Problemas de red:**
- Comprobar la conexión a internet
- Verifique que ningún firewall esté bloqueando el tráfico SIP.

**Compatibilidad con proveedores:**
- Verifique que el proveedor admita llamadas directas (sin registro).
- Comprobar compatibilidad con autenticación IP

## Lista de verificación de pruebas

### Antes de contactar con el soporte técnico

1. **Prueba de salida:**
   - [ ] Credenciales verificadas
   - [ ] Tipo de teléfono seleccionado correctamente
   - [ ] IP fija habilitada con la dirección IP del proveedor
   - [ ] Se intentó realizar una llamada de prueba directa

2. **Prueba de entrada:**
   - [ ] Autenticación IP configurada
   - [ ] Todas las direcciones IP de los proveedores incluidas en la lista blanca de nuestra plataforma
   - [ ] Proveedor configurado para enviar al dominio FQDN (no a la IP directa)
   - [ ] Prueba de llamada desde un número externo

3. **General:**
   - [ ] Conectividad de red verificada

## Preguntas frecuentes

### La transferencia de llamadas no funciona

**P: ¿Por qué no funciona la función de transferencia de llamadas?**

**A:** Si las transferencias de llamadas fallan, pruebe estas soluciones:

1. **Comprobar la configuración de transferencia SIP:**
   - Configurar la transferencia de llamada en modo "Avanzado"
   - Utilice el formato URI SIP: `sip:number@sip-server`
   - Ejemplo: `sip:+1234567890@sip.provider.com:5060`

2. **Verifique el soporte del proveedor:**
   - Confirma que tu proveedor SIP admite SIP REFER.
   - Comprueba si la función de transferencia está habilitada en tu cuenta.
   - Algunos proveedores requieren una configuración específica para las transferencias.

3. **Prueba diferentes formatos:**
   - Prueba con el puerto: `sip:+1234567890@sip-server:5060`
   - Prueba sin puerto: `sip:+1234567890@sip-server`
   - Prueba con un formato sencillo: `sip:+1234567890`

4. **Verificar destino:**
   - Asegúrese de que el número objetivo sea alcanzable.
   - Comprueba si el número responde a las llamadas con normalidad.
   - Comprueba si el número está bloqueado o restringido.

5. **Problemas comunes:**
   - El proveedor no admite SIP REFER.
   - Formato URI SIP incorrecto
   - Solicitudes de transferencia que bloquean la red/firewall
   - El número de destino no responde

**Pasos para la resolución de problemas:**
1. Primero, prueba con un número que sepas que funciona.
2. Pruebe con diferentes formatos de URI SIP.
3. Póngase en contacto con su proveedor de SIP para confirmar la compatibilidad con las transferencias.
4. Revise los registros de llamadas para ver mensajes de error específicos.

## Obtener ayuda

**Al contactar con el servicio de asistencia, proporcione:**
- Mensajes de error de los registros de llamadas
- Configuración de troncal SIP
- Resultados de las pruebas (salientes y entrantes)
- Detalles del intento de transferencia y formato URI SIP utilizado
