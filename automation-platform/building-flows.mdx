## Desencadenar

El punto de inicio del flujo determina su frecuencia de ejecución. Existen varios tipos de activadores disponibles, como el activador programado, el activador de webhook o el activador de eventos, según el servicio específico.

## Acción

Las acciones se ejecutan después del flujo y controlan lo que ocurre cuando se activa dicho flujo, como ejecutar código o comunicarse con otros servicios.
