Este punto de conexión le permite realizar una llamada telefónica.

### Cuerpo de la solicitud

<ParamField body="phone_number" type="string" required>
  El número de teléfono del cliente en formato E.164 (p. ej., +1234567890)
</ParamField>

<ParamField body="assistant_id" type="integer" required>
  El ID del asistente que realizará la llamada
</ParamField>

<ParamField body="variables" type="object">
  Las variables que se pasarán al cliente potencial.
  
  <Expandable title="variables properties">
    <ParamField body="customer_name" type="string" default="<string>">
      El nombre del cliente.
    </ParamField>
    
    <ParamField body="email" type="string" default="<string>">
      El correo electrónico del cliente
    </ParamField>
  </Expandable>
</ParamField>

### Respuesta

<ResponseField name="message" type="string" default="Call initiated successfully">
  El mensaje de la respuesta
</ResponseField>

<ResponseExample>

```json 200 Response
{
  "message": "Llamada iniciada correctamente",
  "data": {}
}
```

</ResponseExample>
