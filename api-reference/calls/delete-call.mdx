---
título: "Eliminar llamada"
API: "ELIMINAR /usuario/llamadas/{llamada}"
descripción: "Eliminar un registro de llamada específico"
---

Este punto de conexión le permite eliminar un registro de llamada específico que pertenece al usuario autenticado.

### Parámetros de ruta

<ParamField path="call" type="integer" required>
  El identificador único de la llamada a eliminar
</ParamField>

### Respuesta

<ResponseField name="message" type="string">
  Mensaje de confirmación que indica que la llamada se eliminó correctamente
</ResponseField>

### Respuestas de error

<ResponseField name="404 Not Found">
  <Expandable title="Error Response">
    <ResponseField name="message" type="string">
      Mensaje de error cuando no se encuentra la llamada o no pertenece al usuario autenticado
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseExample>

```json 200 Success Response
{
  "message": "Llamada eliminada correctamente"
}
```

```json 404 Not Found
{
  "message": "Llamada no encontrada"
}
```

</ResponseExample>

### Notas

- Solo se pueden eliminar las llamadas que pertenecen a asistentes propiedad del usuario autenticado.
- Una vez eliminada una llamada, no se puede recuperar.
- Esta acción eliminará permanentemente el registro de la llamada, incluyendo cualquier transcripción, grabación y metadatos asociados.
- El archivo de grabación de la llamada (si existe) también se eliminará del almacenamiento.
