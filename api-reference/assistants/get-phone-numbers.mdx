---
título: "Obtén los números de teléfono disponibles"
API: "OBTENER /usuario/asistentes/números-de-teléfono"
descripción: "Recuperar todos los números de teléfono disponibles para la asignación de asistentes"
---

Este punto de conexión devuelve una lista de números de teléfono propiedad del usuario autenticado que pueden asignarse a asistentes, con la opción de filtrar por tipo de asistente.

### Parámetros de consulta

<ParamField query="type" type="string" optional>
  Filtra los números de teléfono por tipo de asistente. Opciones: `entrante`, `saliente`
</ParamField>

### Campos de respuesta

<ResponseField name="data" type="array">
  <Expandable title="properties">
    <ResponseField name="id" type="integer">
      El identificador único del número de teléfono
    </ResponseField>

    <ResponseField name="phone_number" type="string">
      El número de teléfono en formato E.164.
    </ResponseField>

    <ResponseField name="country_code" type="string">
       El código de país del número de teléfono.
    </ResponseField>

    <ResponseField name="type_label" type="string">
       La etiqueta de tipo legible para el número de teléfono.
    </ResponseField>

    <ResponseField name="is_available" type="boolean">
      Si el número de teléfono está disponible para su asignación (no está asignado actualmente a un asistente de llamadas entrantes).
    </ResponseField>
  </Expandable>
</ResponseField>

### Notas

- Solo se devuelven los números de teléfono que pertenecen al usuario autenticado.
- Cuando  `type=inbound` se especifica, se filtran los números de identificación de llamadas y los números ya asignados.
- Este  `is_available` campo indica si el número puede asignarse a un nuevo asistente de entrada.
- Los números de teléfono se devuelven en formato de colección de valores (matriz indexada).
- Utilice este `id` campo al asignar números de teléfono a los asistentes.
