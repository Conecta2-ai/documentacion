---
título: "Obtén las voces disponibles"
API: "OBTENER /usuario/asistentes/voces"
descripción: "Recuperar todas las voces disponibles para la configuración del asistente"
---

Este punto de conexión devuelve una lista de todas las voces disponibles que se pueden usar al crear o actualizar asistentes, con la opción de filtrar por modo de asistente.

### Parámetros de consulta

<ParamField query="mode" type="string" optional>
  Filtra las voces por modo de asistente. Opciones: `pipeline`, `multimodal`
</ParamField>

### Campos de respuesta

<ResponseField name="data" type="array">
  <Expandable title="properties">
    <ResponseField name="id" type="integer">
      El identificador único de la voz
    </ResponseField>

    <ResponseField name="name" type="string">
      El nombre que se muestra de la voz.
    </ResponseField>

    <ResponseField name="mode" type="string">
      El modo de asistente con el que es compatible esta voz (`pipeline` or `multimodal`)
    </ResponseField>
  </Expandable>
</ResponseField>

### Notas

- Utilice este `id` campo al crear o actualizar asistentes.
- Este `mode` campo indica con qué motor de asistente es compatible la voz.
- Filtra por modo para obtener solo las voces compatibles con el tipo de asistente que deseas.
- Si no se proporciona ningún filtro de modo, se devuelven todas las voces disponibles.
- Solo se devuelven las voces que son públicas o pertenecen al usuario autenticado.
