---
título: "Deshabilitar webhook del asistente"
API: "POST /user/assistants/disable-webhook"
descripción: "Deshabilitar las notificaciones de webhook para un asistente específico"
---

Este punto de conexión deshabilita las notificaciones webhook para un asistente, deteniendo todas las actualizaciones en tiempo real sobre la finalización de llamadas y datos.

### Cuerpo de la solicitud

<ParamField body="assistant_id" type="integer" required>
  El ID del asistente para deshabilitar el webhook para
</ParamField>

### Respuesta

<ResponseField name="message" type="string">
  Mensaje de éxito que confirma que el webhook se ha deshabilitado.
</ResponseField>

<ResponseField name="data" type="array">
  Matriz vacía (reservada para uso futuro).
</ResponseField>

### Respuestas de error

<ResponseField name="404 Not Found">
  <Expandable title="Error Response">
    <ResponseField name="message" type="string">
      Mensaje de error cuando no se encuentra el asistente o no pertenece al usuario autenticado.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="422 Validation Error">
  <Expandable title="Error Response">

### Comportamiento del webhook

Cuando el webhook está deshabilitado:

- El asistente dejará de enviar solicitudes HTTP POST a la URL de tu webhook.
- Ambos `is_webhook_active` están configurados para `falso` y `webhook_url` stán configurados para `null`
- Las llamadas en curso se completarán normalmente, pero no se enviarán notificaciones webhook.
- Los datos de las llamadas seguirán estando disponibles a través de los endpoints de llamadas a la API.

### Notas

- El asistente debe pertenecer al usuario autenticado
- Esto elimina por completo la configuración del webhook del asistente
- Posteriormente, puedes volver a habilitar los webhooks utilizando el punto de conexión para habilitar webhooks con una nueva URL.
- Deshabilitar los webhooks no afecta la grabación de llamadas ni la recopilación de datos.
