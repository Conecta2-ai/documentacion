---
título: "Habilitar webhook de entrada del asistente"
API: "POST /user/assistants/enable-inbound-webhook"
descripción: "Habilitar notificaciones webhook entrantes para un asistente específico"
---

Este punto de conexión habilita las notificaciones webhook entrantes para un asistente, lo que le permite recibir actualizaciones en tiempo real sobre la finalización de llamadas entrantes y sus datos.

### Cuerpo de la solicitud

<ParamField body="assistant_id" type="integer" required>
  El ID del asistente para habilitar el webhook.
</ParamField>

<ParamField body="webhook_url" type="string" required>
  La URL donde se enviarán las notificaciones del webhook.
</ParamField>

### Respuesta

<ResponseField name="message" type="string">
  Mensaje de éxito que confirma que el webhook se habilitó
</ResponseField>

<ResponseField name="data" type="array">
  Mensaje de éxito que confirma que el webhook se habilitó
</ResponseField>

### Respuestas de error

<ResponseField name="404 Not Found">
  <Expandable title="Error Response">
    <ResponseField name="message" type="string">
      Mensaje de error cuando no se encuentra el asistente o no pertenece al usuario autenticado.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="422 Validation Error">
  <Expandable title="Error Response">
    <ResponseField name="message" type="string">
      Mensaje de error que indica un fallo de validación
    </ResponseField>
    <ResponseField name="errors" type="object">
      Errores de validación detallados para cada campo.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseExample>

```json 200 Success Response
{
  "mensaje": "Webhook habilitado correctamente",
  "datos": []
}
```



</ResponseExample>
