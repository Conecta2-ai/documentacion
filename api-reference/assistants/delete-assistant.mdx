---
título: "Delete assistant"
API: "ELIMINAR /usuario/asistente/{id}"
descripción: "Eliminar un asistente de IA específico"
---

Este punto de conexión le permite eliminar permanentemente un asistente de IA que pertenece al usuario autenticado.

### Parámetros de ruta

<ParamField path="id" type="integer" required>
  El identificador único del asistente a eliminar
</ParamField>

### Respuesta

<ResponseField name="message" type="string">
  Mensaje de confirmación que indica que el asistente se eliminó correctamente
</ResponseField>

### Respuestas de error

<ResponseField name="404 Not Found">
  <Expandable title="Error Response">
    <ResponseField name="message" type="string">
      Mensaje de error cuando no se encuentra el asistente o no pertenece al usuario autenticado
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="500 Internal Server Error">
  <Expandable title="Error Response">
    <ResponseField name="message" type="string">
      Mensaje de error que indica un fallo en la eliminación del asistente.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseExample>

```json 200 Success Response
{
  "mensaje": "Asistente eliminado correctamente"
}
```

```json 404 Not Found
{
  "mensaje": "No se ha encontrado el asistente"
}
```

```json 500 Internal Server Error
{
  "mensaje": "Error al eliminar el asistente"
}
```

</ResponseExample>

### Notas

- Solo se pueden eliminar los asistentes que pertenecen al usuario autenticado.
- Una vez eliminado un asistente, no se puede recuperar.
- Esta acción eliminará permanentemente el asistente y toda su configuración.
- Si el asistente está atendiendo llamadas activas, estas podrían verse afectadas.
