---
título: "Obtén asistentes de salida"
API: "GET /user/assistants/outbound"
descripción: "Recuperar todos los asistentes salientes para el usuario autenticado"
---

Este punto de conexión devuelve una lista de todos los asistentes de llamadas salientes del usuario autenticado. Los asistentes de llamadas salientes se utilizan para realizar llamadas a clientes potenciales y prospectos.

### Campos de respuesta

<ResponseField name="data" type="array">
  <Expandable title="properties">
    <ResponseField name="id" type="integer">
      El identificador único del asistente
    </ResponseField>

    <ResponseField name="user_id" type="integer">
       El ID del usuario propietario de este asistente.
    </ResponseField>

    <ResponseField name="name" type="string">
      El nombre del asistente.
    </ResponseField>

    <ResponseField name="type" type="string">
      El tipo de asistente (siempre será «outbound» para este punto final).
    </ResponseField>

    <ResponseField name="mode" type="string">
      El modo del motor (`pipeline` or `multimodal`)
    </ResponseField>

    <ResponseField name="status" type="string">
       El estado actual del asistente.
    </ResponseField>

    <ResponseField name="voice_id" type="integer">
      El ID de la voz utilizada por el asistente.
    </ResponseField>

    <ResponseField name="language_id" type="integer">
      El ID del idioma utilizado por el asistente.
    </ResponseField>

    <ResponseField name="timezone" type="string">
      La configuración de la zona horaria del asistente.
    </ResponseField>

    <ResponseField name="initial_message" type="string">
      El mensaje inicial que pronunciará el asistente.
    </ResponseField>

    <ResponseField name="system_prompt" type="string">
      La indicación del sistema que define el comportamiento del asistente.
    </ResponseField>

    <ResponseField name="variables" type="object">
       Variables personalizadas definidas para el asistente.
    </ResponseField>

    <ResponseField name="webhook_url" type="string">
       La URL del webhook para las notificaciones 
    </ResponseField>

    <ResponseField name="is_webhook_active" type="boolean">
      Si las notificaciones webhook están habilitadas.
    </ResponseField>

    <ResponseField name="created_at" type="string">
      La fecha y hora en que se creó el asistente.
    </ResponseField>

    <ResponseField name="updated_at" type="string">
      La fecha y hora en que se actualizó por última vez el asistente.
    </ResponseField>
  </Expandable>
</ResponseField>

### Notas

- Este punto de conexión solo devuelve asistentes de tipo "saliente".
- Se devuelven todos los asistentes pertenecientes al usuario autenticado (sin paginación). 
- Utilice estos asistentes con el punto de conexión de llamada para iniciar llamadas salientes.
- Los asistentes de llamadas salientes se pueden utilizar para llamadas de ventas, seguimientos, encuestas y otros escenarios de llamadas proactivas.
