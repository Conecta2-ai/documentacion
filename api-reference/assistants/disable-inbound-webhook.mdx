---
título: "Deshabilitar webhook de entrada del asistente"
API: "POST /user/assistants/disable-inbound-webhook"
descripción: "Deshabilitar las notificaciones webhook entrantes para un asistente específico"
---

Este punto de conexión deshabilita las notificaciones webhook entrantes para un asistente, deteniendo la entrega de actualizaciones en tiempo real sobre la finalización de llamadas entrantes y sus datos.

### Cuerpo de la solicitud

<ParamField body="assistant_id" type="integer" required>
  El ID del asistente para deshabilitar el webhook para
</ParamField>

### Respuesta

<ResponseField name="message" type="string">
  Mensaje de éxito que confirma que el webhook se ha deshabilitado.
</ResponseField>

<ResponseField name="data" type="array">
  Matriz vacía (reservada para uso futuro).
</ResponseField>

### Respuestas de error

<ResponseField name="404 Not Found">
  <Expandable title="Error Response">
    <ResponseField name="message" type="string">
      Mensaje de error cuando no se encuentra el asistente o no pertenece al usuario autenticado.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="422 Validation Error">
  <Expandable title="Error Response">
    <ResponseField name="message" type="string">
      Mensaje de error que indica un fallo de validación. 
    </ResponseField>
    <ResponseField name="errors" type="object">
      Errores de validación detallados para cada campo.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseExample>

```json 200 Success Response
{
  "mensaje": "Webhook entrante desactivado correctamente",
  "datos": []
}
```

```json 404 Not Found
{
  "mensaje": "No se ha encontrado el asistente"
}
```

```json 422 Validation Error
{
  "mensaje": "Los datos proporcionados no son válidos.",
  "errores": {
    "assistant_id": [
      "El campo assistant id es obligatorio."
    ]
  }

```

</ResponseExample>
