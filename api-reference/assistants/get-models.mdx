---
título: "Obtenga los modelos de LLM disponibles"
API: "OBTENER /usuario/asistentes/modelos"
descripción: "Recuperar todos los modelos LLM disponibles para la configuración del asistente"
---

Este punto de conexión devuelve una lista de todos los modelos de lenguaje grandes (LLM) disponibles que se pueden utilizar al crear o actualizar asistentes.

### Campos de respuesta

<ResponseField name="data" type="array">
  <Expandable title="properties">
    <ResponseField name="id" type="integer">
      El identificador único del modelo LLM
    </ResponseField>

    <ResponseField name="name" type="string">
      El nombre para mostrar del modelo LLM.
    </ResponseField>
  </Expandable>
</ResponseField>

### Notas

- Este punto de conexión no requiere ningún parámetro.
- Utilice este `name` campo al crear o actualizar asistentes.
- En una sola solicitud se devuelven todos los modelos LLM disponibles.
- Los diferentes modelos pueden tener capacidades, rendimiento y características de costo variables.
