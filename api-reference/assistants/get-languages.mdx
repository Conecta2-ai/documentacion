---
título: "Obtenga los idiomas disponibles"
API: "OBTENER /usuario/asistentes/idiomas"
descripción: "Recuperar todos los idiomas disponibles para la configuración del asistente"
---

Este punto de conexión devuelve una lista de todos los idiomas disponibles que se pueden usar al crear o actualizar asistentes.

### Campos de respuesta

<ResponseField name="data" type="array">
  <Expandable title="properties">
    <ResponseField name="id" type="integer">
      El identificador único del idioma
    </ResponseField>

    <ResponseField name="name" type="string">
      El nombre para mostrar del idioma.
    </ResponseField>

    <ResponseField name="iso_2" type="string">
      The ISO 639-1 de dos letras del idioma.
    </ResponseField>
  </Expandable>
</ResponseField>

### Notas

- Este punto de conexión no requiere ningún parámetro.
- Utilice este `name` campo al crear o actualizar asistentes.
- El `iso_2` código puede ser útil para funcionalidades específicas del lenguaje.
- En una sola solicitud se devuelven todos los idiomas disponibles.
