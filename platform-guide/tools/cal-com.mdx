## Configurar Cal.com

1. Visita el sitio web [Cal.com](https://cal.com/) y crea una cuenta.
2. Crea un nuevo tipo de evento, por ejemplo "Reunión con asistente de IA".
3. Copie el ID del evento haciendo clic en el tipo de evento y copiando este número de la URL.

<img height="200" src="/resources/cal-event-id.png" />

4. Crea una clave API en Cal.com

## Agrega la herramienta a tu asistente

Agrega esta herramienta a tu asistente y pásale el ID del evento y la clave API.

<img height="200" src="/resources/cal-tool.png" />
