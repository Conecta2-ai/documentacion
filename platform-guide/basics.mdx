# Conceptos básicos de las llamadas automáticas

## Tipos de llamadas

1. Llamadas entrantes: Llamadas recibidas por el sistema
2. Llamadas salientes: Llamadas iniciadas por el sistema

## Campañas

Las campañas son conjuntos organizados de llamadas con objetivos específicos y dirigidos a un público objetivo concreto.

## Clientes

Los leads son clientes potenciales o contactos a los que se dirige una campaña.

## Configuración del asistente

- Motor: Modelo de IA que impulsa la conversación
- Prompt: Instrucciones iniciales para el asistente de IA
- Mensaje inicial: Primer mensaje pronunciado por el asistente
- Idioma: Lenguaje utilizado para la conversación
- Voz: Voz seleccionada para el asistente
- Herramientas: Funcionalidades adicionales disponibles para el asistente
- Extracciones posteriores a la llamada: Datos extraídos después de la llamada para su análisis.

## Plataforma de automatización

Una plataforma sin código para configurar y gestionar llamadas automáticas.


## Provisión de números de teléfono

Proceso de adquisición y configuración de números de teléfono para su uso en campañas.

## Costos

- Coste de las llamadas automáticas por minuto: Cargo por el uso del servicio de llamadas automáticas.
- Costo de Twilio: Cargos adicionales por el uso de los servicios de comunicación de Twilio.

## Herramientas

- Transferencia de llamada: Posibilidad de transferir la llamada a un agente humano.
- Finalizar llamada: Opción para finalizar la llamada
- Integración con el calendario de Cal.com: Funcionalidad de programación integrada con Cal.com
