Una vez que hayas obtenido un número (o configurado SIP o la identificación de llamadas), deberás asignárselo a tu asistente de IA. El proceso es el mismo tanto si usas el número para llamadas entrantes como salientes.

## Asignar un número

1. Ve a **Asistentes** → **(Tu asistente)** → **[Configuración](/ai-assistants/settings/general#phone-number-configuration)**
2. En **Números de teléfono**, seleccione un número de su inventario de Conecta2.ai 
3. Haz clic en **Guardar** para aplicar los cambios.

## Uso de números

Una vez asignado, el número puede utilizarse para:

- **Llamadas entrantes**: Las personas que llamen a este número se comunicarán con su asistente de IA.
- **Llamadas salientes**: El número aparecerá como identificador de llamadas para las campañas de llamadas salientes.
- **Ambos**: El mismo número puede gestionar tanto las llamadas entrantes como las salientes.

## Verificación de número

Para números no alquilados a Conecta2.ai:

- Deberá verificar la propiedad mediante un **código OTP** o una **llamada de verificación.**
- Una vez verificado, el número se puede utilizar tanto para llamadas entrantes como salientes.
- El estado de verificación se mantiene entre diferentes asistentes.

## Pruebas

Antes de la transmisión en vivo:

1. Realice una llamada de prueba entrante para verificar que el asistente responda.
2. Realiza una llamada saliente de prueba para comprobar la visualización del identificador de llamadas.
3. Verifique cualquier función específica (transferencia de llamadas, correo de voz, etc.).

---

**Consejo:** Pruebe siempre la funcionalidad de entrada y salida después de realizar cualquier cambio en las asignaciones de números.
